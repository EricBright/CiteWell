# Owner-provided icon sources

These are the exact SVG files supplied by the project owner for the refresh and
unlink icons, before the renderer's `{{ink}}` / `{{accent}}` tokenisation.

The generated toolbar PNGs are rendered from the tokenised copies one directory
up, not from these files. Keep these as the editable originals and provenance;
if the artwork changes, update both the original here and the tokenised source
used by `tools/render_icons.py`.
