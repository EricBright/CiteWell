# Owner-provided icon sources

These are the exact SVG files supplied by the project owner for the refresh and
unlink icons. They use explicit light-palette colours and open normally in a
vector editor.

The working copies at `source/refresh.svg` and `source/unlink.svg` are identical
copies used by `tools/render_icons.py`; this directory is the archival
provenance copy. If the artwork changes, update both places.

- `refresh.svg` — 2026-11-22 revision
- `unlink.svg` — 2026-11-22 broken-chain revision
