Choose how CiteWell turns web addresses into connections. Every lookup, from the Browse tab or the app, uses this resolver. The default sends encrypted DNS-over-HTTPS queries straight to https://1.1.1.2/dns-query, which blocks known malware domains. Encrypted DNS hides lookups from the local network, but it is not a VPN: sites you visit still see your address. DNS-over-TLS for NextDNS and other custom resolvers is a planned feature; this engine speaks DNS-over-HTTPS today.
