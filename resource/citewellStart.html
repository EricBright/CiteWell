Welcome to CiteWell

A personal fork of Zotero, focused on the interface.

Your library lives on this computer. Online sync with zotero.org is disabled in this build, so nothing is uploaded. To move a library between machines, close CiteWell and copy its data directory.

Getting started

  • Use the New Item button to add a book, article, or webpage.
  • Drag a PDF into the window to attach it to an item.
  • Install the CiteWell Connector in Firefox to save items from the web.
